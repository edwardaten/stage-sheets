    How Stage Sheets works

    Your library lives on this device. Paste a chord sheet, check the key and capo, and export a PDF for forScore.

    Pasting

    • Copy the chords and lyrics from Ultimate Guitar and paste them into the chord sheet box. Spacing is kept, so chords stay over the right words.
    • Lines like Capo: 3, Tuning: Eb or Key: G are read into the fields above.
    • A line starting with ! becomes a red banner. Use it for key changes and big reminders.

    Key and capo

    • Sounds in is the real key. You play is the chord shapes your hands make.
    • With the lock on, moving the capo rewrites the chords so the song still sounds the same.
    • Transpose moves the whole song up or down, for a different vocal range.

    Pages

    • Auto fit picks the largest lyric size that keeps the song on the fewest pages. Pages only break between sections.
    • Condense loops and repeats: sections on the song's main loop print lyrics only, and the loop goes in the chords box. A section on its own loop shows that loop beside its label.
    • A section that repeats exactly becomes a chip in a roadmap line, like PRE-CHORUS → CHORUS. A repeat with a few new words shows only the new lines.
    • If a song won't fit on one page, the sheet switches to two columns before it goes to a second page. Text never goes below 11 pt.
    • When a song runs to a second page, the footer names the next section so you know what's coming.

    Tags and forScore

    • Tags, the artist and the key are written into each PDF. forScore reads them on import, so you can build setlists from tags like Campfire or Jam.

    Sharing and backup

    • Share song file saves a small file a friend can import into their own Stage Sheets.
    • Back up library now and then. It saves every song in one file you can import later.
